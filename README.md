# Tucson Fix & Flip Loan

Astro SSR site on https://tucsonfixandflip.loansapp.cfd/ .

Connector copy: funding sources, Tell Us Your Goal, and a qualified funding-within-48-hours goal. No program rates, fee tables, worked loan-cost examples or fee-sheet fetches. The existing /fix-and-flip-loan-costs/ URL serves the project checklist so older links remain usable.

Build with npm install && npm run build. Preserve the existing Cloudflare Worker configuration, analytics, form handling and domain.
